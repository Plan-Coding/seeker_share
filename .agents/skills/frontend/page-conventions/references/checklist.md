# 页面规范检查清单(Page Conventions Checklist)

新增或修改页面/列表时,逐项核对。以下为默认基线,特殊场景可偏离但需注明理由。

## 列表 / 表格

- [ ] 有搜索输入框,支持关键词过滤(按标题/内容/标签等关键字段)
- [ ] 数据量可能增长的列表提供分页:每页默认 20 条
- [ ] 分页提供 上一页 / 下一页 / 页码 / 总条数(如「共 42 条」)
- [ ] 翻页时保持当前搜索与筛选条件
- [ ] 无数据时显示空状态文案(如「还没有内容」)
- [ ] 搜索无结果显示「未找到匹配项」
- [ ] 行操作按钮分组清晰;危险操作(删除)用 `danger` 样式并放在操作区末尾
- [ ] 受保护数据(内置账户/当前账户)的控件禁用,并有 tooltip/文案说明

## 表单

- [ ] 前端必填/格式校验,错误中文提示
- [ ] 提交中禁用按钮,防止重复提交
- [ ] 成功后重置表单并刷新相关列表
- [ ] 后端校验兜底,异常由全局处理器统一转中文提示

## 危险操作

- [ ] 删除 / 清空 / 停用 / 重置前二次确认(confirm 或 dialog)
- [ ] 确认文案说明影响范围与不可恢复性
- [ ] 批量操作前展示将影响的对象(如列出用户名)

## 状态与反馈

- [ ] 状态用徽章展示(正常 / 已锁定 / 已停用 / 待改密码 等)
- [ ] 成功 / 失败统一 toast 提示,简体中文
- [ ] 数据加载失败有提示,并提供重试入口(刷新按钮)

## 一致性

- [ ] 全部简体中文文案
- [ ] 沿用现有 CSS 类(glass / admin-form / admin-list-panel / status-chip / beam-button 等),不重复造轮子
- [ ] 响应式:移动端列表与操作区合理排布
- [ ] 工具箱工具零第三方依赖、数据不出本机
- [ ] 涉及 JS:`node --check` 通过
